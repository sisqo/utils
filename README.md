# utils

Piccoli script e utility di uso personale.

## bin/

Script eseguibili pensati per essere linkati/copiati in una directory sul `PATH` (es. `~/.local/bin`).

- `cla` — menu interattivo per scegliere un progetto sotto `~/git` e avviarci `claude` dentro (con `--remote-control` e un colore deterministico per progetto).
